    Install

    Updated 6 October 2026

    Nix ships as a small set of container images. One machine with 2 CPU cores and 4 GB of memory comfortably runs a workspace for a household or a small team.

    Requirements#

    • Docker 24 or later with the Compose plugin

    • A domain name if you want to reach Nix from outside your network

    • About 2 GB of disk to start, plus your files

    Run with Docker Compose#

    Save this as compose.yml. It runs the app, the database, the object store and the background workers.

    services:
  nix:
    image: ghcr.io/sianachi/nix:latest
    ports: ["8080:8080"]
    environment:
      NIX_PUBLIC_URL: https://nix.example.org
    depends_on: [postgres]
  postgres:
    image: postgres:17
    volumes: ["db:/var/lib/postgresql/data"]
volumes:
  db: {}

    Start it, then watch the logs until the app reports that it is ready:

    docker compose up -d
docker compose logs -f nix | grep -m1 "ready"

    Tip

    Pin the image to a release tag in production. latest is convenient for trying Nix, not for running it.

    First sign-in#

    Open the address you configured. The first account you create becomes the owner of the first workspace. You can invite others from the workspace settings once you are in.

    Signing in from the command line#

    nixctl talks to the same API as the web app. Sign in once and it remembers the session:

    nixctl login https://nix.example.org
nixctl ws list
