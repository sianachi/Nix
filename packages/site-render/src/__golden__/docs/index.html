    Nix is a self-hosted workspace for running your life and your work in one place. Notes, tasks, tables, canvases, spreadsheets and calendars are not separate apps bolted together. They are all items, and every item can hold other items.

    That one idea does a lot of work. A project is an item whose children are tasks. A reading list is an item whose children are books, shown as a gallery. A journal is an item whose children are dated entries. Views decide how children are shown; they never change what the children are.

    What you get#

    • Items and views. Show the same children as a list, board, gallery, calendar, timeline, table or chart.

    • Canvas and sheets. Draw on an infinite canvas, or work in a spreadsheet with real formulas.

    • Formulas and rollups. Compute properties from other properties, and roll children up into their parent.

    • Live collaboration. Edit together in real time, with presence, comments and named versions.

    • Offline first. Keep working without a connection; changes merge when you are back.

    • Plugins. Extend Nix with sandboxed plugins that add blocks, views and automations.

    Try it in five minutes#

    Nix runs on your own machine or server. If you have Docker, this is enough to start:

    curl -fsSL https://example.org/nix/compose.yml -o compose.yml
docker compose up -d
open http://localhost:8080

    Then follow Install for a production setup, or read Features for a tour.

    Nix is open source and self-hosted.
