    Plugins

    Updated 6 October 2026
    Status
    • Beta

    Plugins add blocks, views and automations. Each runs in its own sandbox with only the permissions you grant.

    A first plugin#

    A plugin is a small package with a manifest and an entry point:

    import { definePlugin } from '@nix/plugin';

export default definePlugin({
  name: 'word-count',
  blocks: {
    count: ({ item }) => `${item.text.split(/\s+/).length} words`,
  },
});

    Plugins run in an isolated worker. They can only read what their manifest asks for, and you approve that when you install one.
