    Items and views

    Updated 6 October 2026
    Status
    • Stable
    On this page
    • One kind of item
    • Views
    • Filters and sorting

    Every list, board and calendar in Nix is a view over an item's children. Add as many views as you like; they share the same items and properties.

    One kind of item#

    A note, a task and a project are the same kind of thing with different properties and children. Turning a note into a project is adding a board, not migrating data.

    Views#

    • List, board, gallery and table for everyday work

    • Calendar and timeline for anything with a date

    • Charts that count or total children by any property

    Filters and sorting#

    Each view keeps its own filters and sort order, so a This week board and an Everything list can sit side by side.
