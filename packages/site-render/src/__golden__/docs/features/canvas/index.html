    Canvas

    Updated 6 October 2026
    Status
    • Stable

    A canvas is an item whose body is a drawing surface. Place notes, shapes, images and other items on it, and connect them.

    Placing items#

    Drag any item from the sidebar onto a canvas to place a live card for it. Editing the card edits the item.

    {
  "kind": "card",
  "itemId": "0199c0de-0000-7000-8000-000000000021",
  "x": 120,
  "y": 80
}
