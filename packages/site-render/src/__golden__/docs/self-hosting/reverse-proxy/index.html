    Reverse proxy

    Updated 6 October 2026

    Put Nix behind a reverse proxy to serve it on your domain with TLS. Caddy needs three lines:

    nix.example.org {
	reverse_proxy localhost:8080
}

    Collaboration uses WebSockets on the same origin; Caddy forwards them without extra configuration.

    Every request passes through the proxy, which routes it by path and host:

  Proxy -->|site hosts| Sites[Sites server]
