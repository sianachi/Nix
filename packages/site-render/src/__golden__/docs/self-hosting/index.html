    Self-hosting

    Updated 6 October 2026
    On this page

    Nix is built to run on hardware you own: a home server, a small VPS, or a single-board computer. This section covers what runs, what to back up, and how to put Nix behind your own domain.

    Upgrading#

    Pull the new tag and restart. Database migrations run on start, before the app accepts requests.

    docker compose pull
docker compose up -d

    Danger

    Take a backup before every upgrade. Migrations are tested, but your data is yours to protect.
