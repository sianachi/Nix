Nix is a self-hosted, collaborative workspace: notes, tasks, canvases, sheets and calendars built from one kind of item. It is what this site is published from.

Why I built it#

I wanted one place for my whole life that I could run on my own hardware, extend without asking anyone, and trust with years of notes.

Under the hood#

  • Core API in .NET with PostgreSQL row-level security

  • Real-time collaboration over Yjs

  • Workers in Go and TypeScript for imports, exports and this site builder

Written and published with Nix.
