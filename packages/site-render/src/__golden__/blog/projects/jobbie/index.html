Jobbie

Role
Engineering lead

Jobbie is an AI-assisted job search platform. It reads a candidate's history once, then does the tedious parts of a search: finding roles that actually fit, explaining why, and drafting applications the candidate edits rather than writes.

How it works#

  • Listings are collected, cleaned and deduplicated nightly.

  • Each listing is matched against a structured profile, not a keyword list.

  • Every suggestion comes with the reasons it was made, so a person can disagree with it.

Stack#

A .NET API, Python workers for extraction and ranking, PostgreSQL with vector search, and a TypeScript front end.

Written and published with Nix.
