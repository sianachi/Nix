The admin panel has no password

30 August 20261 min read
  • security
  • iot

Scan a home network and you will find at least one device whose web admin page opens straight to the settings. No login, no warning. It is usually something nobody remembers installing.

Why it keeps happening#

Devices ship with the panel open so setup is easy, and the step that closes it is optional. Optional security steps are skipped steps.

What to do on your own network#

  • List every device that answers on port 80 or 443

  • Set a password on each admin page

  • Move devices onto their own network segment
