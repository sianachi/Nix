# September 2026

## The companion pet

- ChatGPT companions with explicitly approved workspace tools.
- Animated characters: Owl, Eye of Ra, Demiurge, Fox and Neko, with a launcher you can move.
- Structure tools: the pet can create structured containers, add fields and views, edit forms, set recurrence, apply templates and build whole blueprints, each shown as a preview before it runs.
- Save a subtree as a template from the pet.
- Typed tools for each operation, streaming replies and a redesigned chat.
- Clear reporting of which tool calls are waiting for your decision.

## Notes and files

- Embedded live sections of other notes, editable in place, and explicit page breaks that exports honour.
- Image uploads and resizing in notes, and better table editing.
- PDF and image previews, and Mermaid file previews.
- Imports of Word, PDF and plain text documents as editable notes, with the original kept alongside.

## Structure and data

- Password locks, first for bodies and then for a locked item's whole subtree, its children and its views.
- The habit tracker, with progress, streaks and embedded charts.
- Personal finance: accounts, loans, budgets with actuals, transactions and scheduled postings, edited in place.
- The Drive view for files, available from the New menu.
- Templates with initialisation inputs and attachments that travel with them.
- Bulk assignment, adjustable table widths and rescheduling the end of a span.
- A Date or time field type that accepts either an all-day date or a timed moment.

## Reminders, notifications and automations

- A notification inbox, push notifications through the installed app, quiet hours and per-container muting.
- Due, explicit and habit reminders, with a reminder time for each habit.
- Automations: schedule, date and property-change triggers; notify, set-property and create-item actions; a run log and a dry run.
- `nixctl` commands and MCP tools for notifications, reminders and automations.
- The groundwork for Google and Outlook calendar sync.

## Workspaces and accounts

- A redesigned workspace settings screen and a workspace management menu.
- Archiving and purging workspaces, and trash controls.
- A link to your identity provider's account page for passwords and passkeys.

## The installed app

- Better phone and tablet layouts.
- The app now feels native: right-click context menus, a keyboard shortcuts dialog, copies of opened notes kept on the device, and returning to where you left off.

## Self-hosting

- Docker Compose became the default production target.
- Production runs from multi-architecture images published to the GitHub Container Registry for every commit.
- A one-command release script with a plan, a confirmation, drift preview and a smoke test.
- Verified backups that are restored into isolation before a release proceeds, with off-site copies and a nightly schedule.
