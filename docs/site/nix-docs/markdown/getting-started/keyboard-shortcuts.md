# Keyboard shortcuts

Press **Mod+/** or **?** in Nix to open the full shortcut sheet. **Mod** is Command on a Mac and Ctrl elsewhere; **Alt** is Option on a Mac.

## General

| Shortcut | Action |
| --- | --- |
| Mod+K | Search and commands |
| Mod+Alt+N | New note |
| Mod+\\ | Show or hide the sidebar |
| Mod+Alt+Z | Zen mode: the current page with workspace navigation hidden |
| Escape | Leave Zen mode (when focus is not in a text field or dialog) |
| Mod+\[ | Go back |
| Mod+\] | Go forward |
| Mod+/ or ? | Keyboard shortcuts |
| Shift+F10 or the Menu key | Actions for the focused row, tab or card |

New note is Mod+Alt+N rather than Mod+N because browsers keep Mod+N for a new window.

## Editor

| Shortcut | Action |
| --- | --- |
| Alt+Enter | Link the underlined item name at the caret |
| / | Open the slash menu to insert a block |
| \[\[ or @ | Insert a reference to another item |

The editor can also use Vim (Normal, Visual and Visual Line modes) or Emacs (kill ring and mark) key bindings. Turn them on in settings.

## Views

| Shortcut | Action |
| --- | --- |
| Mod+Shift+D | Fill the selected spreadsheet cells down as a series |

## Outline view

| Shortcut | Action |
| --- | --- |
| Enter | Add an item below the chosen row |
| Tab or Alt+Right | Move inside the row above |
| Shift+Tab or Alt+Left | Move out of its parent |
| Mod+Up or Alt+Up | Move up among its siblings |
| Mod+Down or Alt+Down | Move down among its siblings |
| Mod+Enter or Alt+Enter | Open the chosen item |
| Escape | Let the next Tab leave the outline |

## Panes and tabs

| Shortcut | Action |
| --- | --- |
| F6 | Next pane |
| Shift+F6 | Previous pane |
| Delete or Backspace | Close the focused tab |

## Workspace tree

| Shortcut | Action |
| --- | --- |
| Alt+Enter | Open the focused row beside the current one |
| Alt+Up | Move up among its siblings |
| Alt+Down | Move down among its siblings |
| Alt+Right | Move inside the row above |
| Alt+Left | Move out of its parent |

Global shortcuts pause while a dialog is open, so typing in a dialog never triggers them.
