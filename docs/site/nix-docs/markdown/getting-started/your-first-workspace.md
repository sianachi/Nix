# Your first workspace

When you first sign in, Nix creates a personal workspace for you. You can create more workspaces later, share them with other people and move items between them.

## The screen

- **The rail** down the left edge holds your destinations: Notes, Daily notes, Calendar, Graph, Bookmarks, Smart lists, Templates, Automations, Import, Trash, the Pet and Settings. **Mod+K** opens search and commands from anywhere.
- **The workspace tree** shows your items. Drag a row to move it, or drop it between rows to reorder. On a phone the tree becomes a drawer.
- **The item screen** shows the selected item's body and, below or beside it, its views.

You can open items in tabs, pin tabs, split the screen into panes and drag tabs between them. Zen mode hides the workspace navigation so only the current page remains.

## Create something

Choose **New** in the sidebar. It offers six things:

| Entry | What you get |
| --- | --- |
| Note | A rich text page |
| Canvas | A drawing and diagram surface |
| Sheet | A spreadsheet body with A1 formulas |
| Upload files | File items with previews and versions |
| Structured | A container set up as a list, board, calendar, timeline, gallery, spreadsheet, form, interactive form, smart list or chart |
| From a template | A copy of a saved template tree |

Each one asks for a title and a location. Any item can hold children, whatever its body, so a note can contain sub-notes and a sheet can contain tasks.

## Daily notes

**Today** opens the note for the current day, filed under Year and Month folders. A quick capture dialog appends to it without leaving what you are doing. Daily notes can be switched off per workspace.

## Give a container fields

Open a container's settings and find **Fields for the items inside this one**. Add a field, choose its type and save. Every item inside, and everything inside those, inherits the field. For example, a Projects container might declare:

- Status: a select with Planned, Active and Done
- Due: a due date
- Owner: an assignee
- Budget: a number

Edit values from the item itself or in place in a list or spreadsheet view.

## Switch views

With fields in place, add views from the view switcher above the children:

- a **Board** grouped by Status;
- a **Calendar** placed by Due;
- a **Chart** totalling Budget by Status.

Each view keeps its own filters, sorts, grouping and column summaries. Views never copy items: changing a card on the board changes the same item you see in the list.

## Share a workspace

From the workspace settings you can invite people, choose their role (owner, editor or viewer), revoke invitations and remove members. Every read and write is checked against the member's role on the server, so a view or a search never shows someone an item they cannot read.
