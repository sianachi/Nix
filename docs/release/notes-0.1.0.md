# Nix 0.1.0

The first numbered release. Everything below is what the release adds on top of the running
production builds; see `CHANGELOG.md` for the detailed list.

- The New menu offers every structured item type, including charts.
- Columns can be resized in list and spreadsheet views, per device.
- Device sync can be turned off, hiding the footer entirely.
- Workspaces can be grouped and pinned in the workspace menu, per person.
- Items can be selected in bulk and moved together; rename, move and delete are offered from every view that supports them.
- Notes can be edited as Markdown and applied back, with undo.
- MCP is available remotely over HTTP with personal access tokens, plus note and item tools.
- Sites are off by default and enabled only on the designated production deployment.
- Pets can use Claude or OpenRouter with your own API key, alongside ChatGPT.
- Per-view control over how items open, with a context-aware default.
