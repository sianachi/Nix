# v0.1.0 release checklist

Prepared 13 October 2026. Nothing here has been executed; tagging, publishing and deploying are the
owner's actions.

1. Merge the stacked PRs in order: #122, #123, #124, #125, #126, #127, #128, then the release prep PR.
2. Wait for `ci-images.yml` on the resulting `main` SHA; note the full SHA.
3. Run the deploy smoke on the Compose host: `release-tools smoke --preflight`, then
   `deploy/compose/release.sh <sha>`; on the k3s host, `deploy/k8s/deploy.sh` from a clean `main`.
4. Confirm: Settings shows the MCP tab; sites are off on Home and on at nixsites.com; a pet on
   ChatGPT still answers; column widths persist after reload.
5. Move the `Unreleased` section of `CHANGELOG.md` to `0.1.0 - <date>` and commit.
6. Tag and push (owner):

   ```sh
   git tag -a v0.1.0 <sha> -m "Nix 0.1.0"
   git push origin v0.1.0
   gh release create v0.1.0 --title "Nix 0.1.0" --notes-file docs/release/notes-0.1.0.md
   ```

7. Record the SHA and date in `CLAUDE.md` and the release ledger.
